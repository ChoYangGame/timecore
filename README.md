## 1. 게임 제목 및 한 줄 소개

# 시간관리국 · TimeCore

> **무너진 시간선을 복구하러 네 개의 시대를 건너뛰는 브라우저 생존 액션.**

시간관리국 요원이 되어 **원시 → 중세 → 현대 → 미래** 네 시대를 차례로 지나며 각 시대의 보스를 처치하고 시간선을 복구합니다. 몰려오는 적을 자동으로 공격하며 버티고, 레벨업마다 증강을 골라 자신만의 빌드를 쌓아 갑니다.

**시대가 바뀔 때마다 맵·적·필드 기믹·보스·배경음악이 통째로 갈립니다.** 한 판은 **5분 안팎**을 목표로 설계했습니다.

| 항목 | 내용 |
|---|---|
| 장르 | 2D 탑다운 액션 로그라이트 (생존 · 자동 전투 · 빌드 쌓기) |
| 플레이 시간 | 1회 약 5분 |
| 인원 | 1인 |
| 플랫폼 | PC 웹 브라우저 (설치 불필요) |
| 조작 | 키보드 `WASD` + 마우스 클릭 |

## 3. 게임 방법

### 3.1 목표

> **네 시대(원시 → 중세 → 현대 → 미래)의 보스를 모두 처치해 시간선을 복구하는 것**이 최종 목표입니다.

한 시대의 흐름은 다음과 같습니다.

```
웨이브 1 ~ 4  (각 15초, 총 60초)      적이 점점 많아지고 강해짐
        ↓
웨이브 5 : 보스 등장                   시대 전용 보스 + 전용 패턴 3종
        ↓
보스 처치 → 아레나 중앙에 모래시계 출현
        ↓
모래시계 획득 → 암전 → 다음 시대       맵·적·기믹·보스·BGM이 전부 교체
```

- 레벨·증강·최대 체력·남은 체력은 **시대가 바뀌어도 그대로 이어집니다.** 한 판이 통째로 이어지는 구조입니다.
- 시대가 올라갈수록 적의 체력과 성격이 달라집니다(3.6 참고).
- **모래시계를 먹어야 다음 시대로 넘어갑니다.** 보스를 잡았다고 자동으로 넘어가지 않으니, 숨을 고르고 아레나 중앙으로 이동하세요.

### 3.2 조작

| 입력 | 동작 |
|---|---|
| **`W` `A` `S` `D`** | 이동 (8방향) |
| **(자동)** | **공격은 자동입니다.** 가장 가까운 적을 스스로 조준합니다 |
| **마우스 클릭** | 레벨업 시 나타나는 증강 카드 3장 중 하나 선택 |
| **마우스 클릭** | 타이틀의 직업 선택 · 랭킹 열기 · 재시작 등 모든 버튼 조작 |
| **`ESC`** | 일시정지 (재개 / 재시작) |

> **공격 버튼이 없습니다.** 플레이어가 판단해야 하는 것은 *어디에 서 있을 것인가*와 *어떤 증강을 고를 것인가* 두 가지입니다.

### 3.3 게임 시작 순서

1. 타이틀 화면에서 **이름**을 입력합니다 (선택 사항, 영문 대문자·숫자 8자까지). 비워 두면 익명으로 플레이하며 랭킹에 등록되지 않습니다.
2. `RANKING` 버튼으로 현재 순위표를 볼 수 있습니다.
3. **`파견 시작`** 을 누릅니다.
4. **직업 3종 중 하나**를 고르면 즉시 판이 시작됩니다.

### 3.4 직업 3종

시작할 때 한 번 고르며, 판 도중에는 바꿀 수 없습니다. 직업에 따라 **등장하는 증강도 달라집니다.**

| 직업 | 공격 방식 | 플레이 감각 |
|---|---|---|
| **GUNNER** (거너) | 가장 가까운 적을 향해 **총알을 자동 발사**. 다중 사출·관통으로 확장 | 가장 무난하고 사거리가 깁니다. **처음이라면 이 직업을 권합니다** |
| **BLADE** (블레이드) | 주기마다 가장 가까운 적 쪽으로 **시간의 홀을 휘두름**. 홀 그림이 지나간 자리가 곧 타격 범위 | 사거리가 짧아 적에게 파고들어야 합니다. 대신 한 방이 셉니다 |
| **MAGE** (매지션) | 몸을 중심으로 **지속 피해 지대**가 항상 켜져 있음. 조준도 사거리 개념도 없음 | **어디에 서 있느냐가 곧 공격**입니다. 적 무리 한가운데를 밟고 버팁니다 |

### 3.5 종료 조건

판은 아래 **두 가지 경우에만** 끝납니다.

#### ① 패배 — 체력이 0이 되면

> 결과 화면 **`시간선 붕괴`** 가 표시됩니다.

표시되는 기록: **생존 시간 · 처치 수 · 레벨 · 도달 웨이브 · 도달 시대**

- 플레이어의 최대 체력은 **100**에서 시작하며, 레벨업과 증강으로 늘어납니다.
- 적과 접촉하거나, 시대 기믹(균열·전기·폭격·레이저)·보스 패턴에 맞으면 체력이 줄어듭니다.
- 회복 수단은 **회복 코어**뿐입니다(3.7 참고). 자동 회복은 없습니다.

#### ② 승리 — 미래 시대의 보스를 처치하면

> 결과 화면 **`역사 복구 완료`** 가 표시됩니다.

표시되는 기록: **생존 시간 · 처치 수 · 레벨 · 최종 웨이브**

#### 두 경우 모두

- 결과 화면 오른쪽에 **랭킹**이 함께 표시됩니다.
- **`재시작`** 버튼으로 처음부터 다시 시작할 수 있습니다.
- `ESC` 일시정지 화면에서도 언제든 재시작할 수 있습니다.

### 3.6 시대별 특징 — 무엇이 바뀌는가

| 시대 | 적 성격 | 필드 기믹 | 보스 |
|---|---|---|---|
| **원시** | 야수 떼 — 약하고 빠르고 **수가 많음** | **지면 균열** — 땅이 지그재그로 갈라짐 | 고대의 포식자 |
| **중세** | 중장 보병 — 느리고 **단단함** | **전기 방전** — 아크가 튀며 깜빡임 | 강철의 심문관 |
| **현대** | 기계화 보병 — **물량과 속도** | **십자 폭격** — 끝에서부터 순차 폭발 | 강화 병기 |
| **미래** | 소수 정예 — 가장 단단하고 가장 빠름 | **레이저 격자** — 다중 레이어 광선 | 시간의 지배자 |

> 압박의 출처를 시대마다 일부러 다르게 뒀습니다. **중세는 버티는 싸움, 현대는 쫓기는 싸움**입니다.
> 모든 기믹은 **예고 표시가 먼저 뜨고 그다음에 발동**합니다. 예고를 보고 피할 수 있습니다.

보스는 시대마다 **전용 패턴 3개**를 가집니다(총 12패턴). 돌진·낙인·포탑 전개·시간 정지 영역·위상 도약 등이 있으며, **보스전 중에도 시대 기믹은 계속 돌아갑니다.**

### 3.7 필드에서 만나는 것들

| 오브젝트 | 설명 |
|---|---|
| **경험치 구슬** | 적을 처치하면 떨어집니다. 가까이 가면 빨려 들어옵니다. 보스를 처치하면 필드에 남은 구슬이 전부 자석처럼 끌려옵니다 |
| **회복 코어** | 잠시 머무르면 체력을 회복합니다. **이 게임의 유일한 회복 수단**입니다 |
| **시간 감속 지대** | 보라색 원형 장판. **플레이어와 적 모두** 이동이 느려집니다. 적을 끌고 들어가면 이득, 혼자 늦게 밟으면 손해입니다 |
| **모래시계** | 보스를 처치하면 아레나 중앙에 나타납니다. 획득하면 다음 시대로 넘어갑니다 |
| **적 출현 표식** | 적이 나타나기 전에 바닥에 뜨는 예고 표식입니다. 그 자리에서 적이 나옵니다 |

### 3.8 성장 — 레벨업과 증강

- 경험치가 차면 레벨업하고, **증강 카드 3장** 중 하나를 마우스로 고릅니다. 카드를 고르는 동안 게임은 멈춥니다.
- 증강은 **총 23종**이며, 직업 공용 증강과 직업 전용 증강이 섞여 나옵니다.
- 대표 증강 — `시간 가속`(이동속도) · `크로노 오버클럭`(공격 속도) · `붕괴 증폭`(피해량) · `시간 왜곡`(경험치 획득 범위) · `균열 복구`(최대 체력) · `관통 코어` · `다중 사출` · `위상 이동`(피격 시 짧은 무적)
- 레벨업 시 **최대 체력도 함께 조금씩 늘어납니다.**

### 3.9 AI 디렉터 — 판을 읽고 개입합니다

이 게임에는 플레이 상황을 관찰해 난이도에 개입하는 **규칙 기반 디렉터**가 있습니다.

| 판단 | 개입 |
|---|---|
| **위기** (체력이 낮음) | 회복 코어 배치 |
| **과잉 화력** (너무 쉽게 밀어냄) | 다른 시대의 개체 난입 |
| **전선 정체** (화면이 한산함) | 출현 주기 단축 |
| **전선 고정** (한자리에서만 싸움) | 그 자리에 시간 감속 지대 생성 |

> 개입할 때마다 화면에 **"왜 그랬는지"가 두 줄 배너로 표시됩니다.** 판단 근거가 보이지 않으면 플레이어에게는 그냥 무작위로 느껴지기 때문입니다.

### 3.10 랭킹 — 로그인 없이 이름만

- 타이틀에서 이름을 입력하면(영문 대문자·숫자 8자) 판이 끝날 때 자동으로 등록됩니다.
- 순위는 **① 도달 시대 → ② 시간** 순으로 정렬됩니다. **클리어는 빠를수록, 사망은 오래 버틸수록** 위로 올라갑니다.
- 타이틀의 `RANKING` 버튼과 결과 화면에서 볼 수 있으며, 자신의 기록은 굵게 표시됩니다.
- 이름을 비워 두면 등록하지 않고 익명으로 플레이합니다.

## 4. 처음 플레이하는 분을 위한 팁

1. **직업은 GUNNER로 시작하세요.** 사거리가 길어 가장 안정적입니다.
2. **멈춰 있지 마세요.** 공격이 자동이므로 손이 하는 일은 회피뿐입니다. 계속 움직이면서 적을 뒤로 끌고 다니는 편이 안전합니다.
3. **바닥의 예고 표시를 보세요.** 균열·전기·폭격·레이저는 전부 터지기 전에 자리를 먼저 알려 줍니다.
4. **초반 증강은 공격 속도나 이동 속도를 권합니다.** 후반에 적이 단단해지므로 화력을 먼저 굴리는 편이 편합니다.
5. **감속 지대는 도구로 쓰세요.** 적을 끌고 들어간 뒤 빠져나오면 안전하게 정리할 수 있습니다.
6. **보스를 잡은 뒤 서두르지 마세요.** 모래시계를 먹기 전까지는 다음 시대가 시작되지 않습니다. 체력과 위치를 정리할 시간입니다.
