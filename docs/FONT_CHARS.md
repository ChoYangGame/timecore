# 폰트 서브셋 문자 목록

> Static SDF라 새 글자가 생기면 다시 구워야 한다.
> UI 작업이 전부 끝난 뒤 한 번에 굽는다. 그때까지 여기에 누적.
> 굽는 법: Assets/Fonts/Pretendard SDF 선택 → Inspector의 Update Atlas Texture
>          → Custom Characters에 아래 문자열 → Generate → Save (Save as 아님)
> 설정: Padding 5px / Atlas 1024×1024 / SDFAA
> 소스: fonts/Pretendard-Regular.ttf (굽기 전 Assets/에 임시 복사 필요)

`TMP_FontAsset`이 아니라 `UnityEngine.TextCore.Text.FontAsset` 타입이 생성돼 씬의 TMP 참조가
전부 끊긴다. (2026-08-02 실제 발생 — docs/AI_LOG.md 참조)

## 굽고 나서 반드시 할 것

TMP는 폰트를 다시 구워도 **인메모리 조회 테이블이 갱신되지 않아** 새 글자가 LiberationSans로
폴백된다. 애셋 자체(`characterTable`/`glyphTable`)는 멀쩡한데 화면만 □로 보이므로 오진하기 쉽다.
`HasCharacter()`가 true를 반환해도 렌더는 폴백될 수 있다.

해결: `AssetDatabase.ImportAsset(ForceUpdate)` → `ReadFontAssetDefinition()` → **씬 재로드**.
Play 모드 재진입만으로는 풀리지 않는다. (2026-08-02 실제 발생)
