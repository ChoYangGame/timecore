## 3. 남은 일 (우선순위 순)

### (1) `f135734` 재빌드·재배포 — 가장 먼저 처리

커밋·푸시는 끝났지만 배포본에는 안 들어가 있다. 빌드 5분 + 배포 1분이면 된다.
(`BuildPipeline`이 Sentis 셰이더 경고로 "failed"를 오보고하는 건 정상이다.
콘솔 에러 0건 + `Build/` 타임스탬프로 판정할 것.)

### (2) 사람이 직접 한 판 완주 — 아직 없음

자동 드라이버 실측만 있고 사람이 완주한 기록이 없다. 완주하면 `docs/AI_LOG.md`를 추정치 → 실측치로 갱신.

같이 회수할 것:
- `[AnomalyDirector]` 개입 로그 + `GetActivitySummary()` (판 종료 시 자동 출력됨)
- **`OnDestroy` 자동 덤프의 실제 Play 종료 경로가 아직 미검증이다** (`b413c90`).
  완주 후 콘솔에 요약이 1회만 찍히는지(중복 없이) 확인하면 이 항목이 닫힌다.

### (3) 밸런스 — 미검증 항목이 늘었다

전부 사람 눈으로 안 본 값이다.
- **보스전이 가만히 서 있으면 7.6초 만에 죽는다**(무인 테스트 실측). 의도된 난이도인지 판단 필요.
- 보스 12패턴 중 후보: 미래 1번(감속 지대 3장 + 방사 12발), 원시 1번(3연 돌진 speed 12).
- 보스전 기믹 간격 배수: `EraHazardSpawner` 1.7배 / `RiftZoneSpawner` 2.0배. 겹쳐 죽으면 더 올릴 것.
- **히트스톱이 저사양 브라우저에서 렉으로 느껴지는지.** 거슬리면
  `CameraShake.HandlePlayerHit`의 `Hitstop.Do` 한 줄만 제거하면 된다.

### (4) 빌드 용량 33.2MB — 줄일지 판단 필요

증가분은 전량 맵 4장이다(1장당 약 4.7 MiB). 코드 비용은 사실상 0
(이번 VFX 작업 전체가 +20,373 bytes였다 — 새 에셋을 하나도 안 썼기 때문이다).
유일한 큰 손잡이는 `maxTextureSize` 2048 → 1024 (4장 합계 약 18.7 → 4.7 MiB).
다만 아레나 폭이 25유닛이라 뭉개질 수 있다. **필요하면 1024 비교 캡처를 만들어 판단받을 것.**

### (5) 제출 준비

`docs/AI_LOG.md`가 제출 문서의 핵심이다. 실패·되돌린 결정·오진단이 이미 다수 기록돼 있다.
새 작업을 할 때마다 같은 밀도로 append할 것(항목당 8줄 이내).

  (2026-08-05에 모달 다이얼로그로 8분 차단됐다. CLAUDE.md 하드 룰)
- 폰트를 코드로 구우려 시도하지 말 것. `AssetDatabase.DeleteAsset`도 MCP에서 차단된다
  (2026-08-07 확인 — 파일 삭제 + `AssetDatabase.Refresh()`로 우회).
- 요청 없는 리팩터링·새 프리팹 추가 금지.
- `BackgroundGrid.cs`는 비활성 유지, 손대지 않는다.
- 새 패키지·에셋 도입 전에 반드시 먼저 물어볼 것 (빌드 용량 = 로딩 시간).
- `Unity_RunCommand`는 **`System.Reflection` 네임스페이스를 차단한다.** 런타임 값을 들여다볼 때는
  `SerializedObject`나 공개 프로퍼티를 쓸 것.

## 5. Play 모드로 실측할 때 (이번에 세 번 헛짚었다)

1. **`TitleController.StartRun()`을 먼저 부르지 않으면 `GameManager.Instance`가 null이다.**
   그러면 스포너 `CanFire()`/`CanSpawn()`이 전부 false를 반환해 "기능이 안 된다"로 오진하게 된다.
2. **무인 플레이어는 보스전에서 7.6초 만에 죽는다.** 죽으면 `IsGameOver`로 모든 스포너가 멎는다.
   관측 창이 필요하면 `Health.SetMaxHp(1000000f)`로 올려 두고 볼 것.
3. **Play 세션을 오래 켜 두면 상태가 오염된다**(웨이브가 혼자 진행돼 보스가 이미 소환됨).
   실측 전에 반드시 Play를 껐다 켤 것.
4. 순간적으로 생겼다 사라지는 것(빔 수명 약 2.5초)은 점 샘플링으로 못 잡는다.
   **bool을 반환하는 공개 API**(`RiftZoneSpawner.SpawnOnPlayer()`, `RecoveryCoreSpawner.Spawn()`)로
   게이트 자체를 직접 검증하는 쪽이 확실하다.
5. 시간 의존 연출을 캡처할 때는 `Time.timeScale`을 0.1로 낮춘다. `_elapsed`가 `Time.deltaTime`
   기반이라 비율은 그대로고 실제 시간만 늘어난다.
