## 해결 완료

| # | 지적사항 | 해결 방법 | 커밋 |
|---|---|---|---|
| 1 | 디버그 키 B/N이 빌드에 살아 있음 | 필드·사용부를 `#if UNITY_EDITOR`로 감쌈. EraManager는 Update에 디버그 키뿐이라 메서드 전체를 감싸 빌드에서 콜백 자체가 제거됨 | `f04e114` |
| 2 | 게임오버 + 재시작 없음 | `GameOverController`(HUD_Canvas)가 `Health.OnDeath`를 받아 스폰 중단·결과 표시·`timeScale=0`. "재파견"이 `timeScale` 복구 후 씬 리로드. `GameManager.IsGameOver`로 증강 카드·시대 전환 코루틴과의 timeScale 충돌을 4방향 방어 | `f04e114` |
| 4 | 타이틀 화면 + 조작 안내 | `TitleController`가 Awake에서 `timeScale=0`으로 멈추고 `TitlePanel` 표시. "파견 시작"에 조작 안내(이동/공격/증강 선택) 동봉. 첫 프레임 deltaTime 누수(0.02초) 실측 후 `GameManager.ResetRunTimer()`로 정확히 0부터 계측 | `f920c23` |
| 5 | 클리어 화면 (`OnGameClear` 구독자 없음) | `GameOverController`를 확장해 사망·클리어 양쪽 처리. 별도 컨트롤러를 만들지 않은 이유는 timeScale 충돌 방어가 전부 `IsGameOver` 하나에 걸려 있어 결말별 플래그를 두면 가드를 통째로 복제해야 하기 때문. 제목·마지막 행 라벨만 교체하고 클리어 시 시대 이름은 숨김 | `f920c23` |

### #4 · #5 검증 기록 (Play 모드 실측)

| 시나리오 | 결과 |
|---|---|
| 타이틀 대기 | 시간·웨이브·스폰 전부 정지, timeScale 0 |
| 파견 시작 | `SurvivalTime` 정확히 0부터 (누수 0.02초 제거 확인) |
| 클리어 순간 레벨업 겹침 | 레벨 25로 올라가도 카드 미표시, timeScale 0 유지 |
| 클리어 표시 내용 | 제목 `역사 복구 완료`, 라벨 `최종 웨이브`, 시대 텍스트 숨김 |
| 클리어 → 재파견 | 씬 리로드 후 타이틀부터 재시작, 전 상태 초기화 |
| **보스 처치와 사망 동시** | 먼저 도착한 쪽이 확정되고 나중 것은 `IsGameOver`에서 차단 — 결과 하나만 표시 |

### #2 검증 기록 (Play 모드 실측)

| 시나리오 | 결과 |
|---|---|
| 정상 사망 | timeScale 1→0, 패널 표시, 스폰 중단, 결과값 정상 |
| 사망 후 레벨업 겹침 | 레벨 25까지 올라가도 카드 미표시, timeScale 0 유지 |
| 증강 카드 표시 중 사망 | 카드 닫힘 + 게임오버 표시, timeScale 0 유지 |
| **시대 전환 페이드 중 사망** | `ApplyEra()`가 이미 스폰을 True로 되돌린 시점(alpha 0.88)에 사망시켜 실측 — `AbortTransition()`이 코루틴 중단·페이드 제거, 이후 스폰 False 확정 |
| 재시작 | timeScale 1 복구, HP 100/100, 웨이브 1, 원시 시대로 초기화 |

⚠️ **폰트 미반영**: 게임오버·타이틀·클리어 화면의 34자가 아직 안 구워져 개발 중에는 □로 보인다.
