### G1 기각 철회 근거 (2026-08-05, D-3)

2026-07-31에 4시대 → 2시대로 줄인 이유는 **남은 일정 대비 제작 비용**이었다.
그 전제가 아래 두 가지로 사라져서 결정을 뒤집었다.

1. **맵 아트 4종이 이미 완성됐다.** 디자인이 `현대시대.png`·`미래시대.png`를 전달했고,
   기존 2종과 규격이 완전히 동일하다(3344×1882 → 임포트 후 2048×1153, PPU 82.07,
   월드 24.96×14.05). inset(1.7, 1.6)도 그대로 통해 아레나 재조정이 필요 없었다.
2. **적·보스가 전부 placeholder(흰 사각형 + 틴트)라 추가 아트 비용이 0이다.**
   시대 구분은 `EraConfig.enemyColor`/`bossColor`로 색만 주입하면 끝나고,
   프리팹은 기존 2종(`Enemy`/`MedievalEnemy`)을 그대로 재사용했다 — 새 프리팹 0개.

실제 비용은 코드 5개 파일 수정 + 씬 배선 8칸이었다.
`EraConfig` 기본값을 C# 필드 이니셜라이저에 넣어 두니 Unity가 신규 배열 필드를
그 값으로 역직렬화해서, 인스펙터 수작업 없이 `enemyPrefab` 4칸 + 배경 4칸만 주입하면 됐다.

플레이 시간은 웨이브 구간을 시대당 125초 → **60초**로 줄여(25s×5 → 15s×4) 맞췄다.
4시대 웨이브 구간 합계는 **240초 확정**이고, 여기에 보스전 4회 + 전환 3회가 붙는다.
2시대 시절 실측(288초)에서 역산한 보스전·전환 비용(시대당 약 19초)을 그대로 쓰면 **약 5분 20초** 추정이다.
단 보스 HP가 시대별로 최대 1.75배까지 오르고 웨이브 단축으로 증강 획득이 줄어서
후반 보스전이 더 길어질 수 있다 — **실시간 완주 실측은 아직 없다(사용자 플레이 필요).**
